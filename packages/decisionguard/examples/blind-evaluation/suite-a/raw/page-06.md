# 금요일 기록

시험 환경의 11월 6일 빌드에서 저렴한 대체품 수락, 명시적 거절, 후보 없음의 세 경로를 실행했다. 세 경로 모두 주문 품목 상태와 환불 금액이 합의한 규칙과 일치했다. 이것은 시험용 결제 연동 결과이며 실제 결제사의 환불 완료까지 확인한 기록은 아니다.

오전 10시 정각 응답은 서버에서 거절됐지만 고객 화면에는 잠깐 수락 완료가 표시됐다. 새로고침 뒤에는 환불 예정으로 바뀌었다. 표시 오류는 아직 열려 있고 수정 담당자는 정해졌다. 정각 응답 처리 전체가 통과했다고 보고하지 않기로 했다.

무응답 마감, 제외 채소 후보 차단, 환불 요청 세 번 재전송은 다음 주에 시험할 항목이다. 아직 실행 결과는 없다. 휴대폰 시계가 7분 빠른 경우에도 서버 기준으로 처리되는지 함께 확인할 예정이다.
