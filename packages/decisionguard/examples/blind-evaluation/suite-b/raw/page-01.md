# 여름의 공책

잎소리는 개인 탐조 기록을 모으는 앱이다. 8월 회의에서는 인터넷이 끊기면 저장 버튼을 비활성화하고 연결이 돌아온 뒤 새로 입력하도록 하는 방식을 채택했다. 기기 안에 미전송 기록을 두면 상태 설명이 복잡해진다는 이유였다.

동일 계정의 여러 기기가 같은 관찰 기록을 동시에 편집하는 기능도 가을에 넣자는 제안이 있었다. 충돌 시각이 늦은 편집을 남기자는 의견이 나왔으나 승인된 설계나 작업 일정은 없다.

새 기능 안내에 사진도 자동 전송된다고 써 보자는 문구 초안이 남아 있다. 이 초안은 문구 검토용이며 사진 전송 기능을 제공하기로 한 결정은 아니다.
