# 짧은 실행 노트

11월 7일 Android 시험 기기에서 비행기 모드로 기록을 저장하고 앱을 정상 종료한 뒤 다시 열었다. 기록의 종, 마릿수, 관찰 시각과 전송 대기 표시가 남아 있었다. 위치 권한을 거부한 별도 실행에서도 저장은 됐다. 이 노트에는 iOS 실행 기록이 없다.

응답을 받기 직전에 연결을 끊었다가 다시 보내기를 두 번 눌렀다. 서버에는 기록이 한 건만 생겼지만 기기 목록에는 전송 완료와 전송 대기 행이 한 줄씩 중복 표시됐다. 화면을 다시 열어도 두 줄이 남았고 문제는 아직 해결되지 않았다. 서버 중복 저장은 관찰되지 않았다는 사실과 화면 문제를 나누어 기록한다.

로그인 만료 상태의 재전송, 서버 확인 직후 강제 종료, 필수 항목 누락, 저장 공간 부족은 다음 실행 묶음에 남아 있다. 이 네 항목은 아직 실행하지 않았다. 다음 묶음에서 iOS도 확인하자는 요청은 있었으나 시험 기기 확보일은 정해지지 않았다.
