# 보랏빛 파일

10월 23일 자료 담당자가 가상 서비스 산새첩의 공개 시연을 봤다. 시연에서는 연결을 끊은 상태에서 종 이름과 마릿수를 입력한 뒤 기기에 저장됐다는 표시가 떴다. 연결을 복구한 다음 서버 목록에 같은 기록이 한 번 나타났다. 시연자가 어떤 실패 상황을 미리 제외했는지는 알 수 없다.

가상 서비스 들빛노트의 소개문에는 오프라인 관찰 기록이라는 문구가 있었지만 직접 실행해 보지 못했다. 특히 중복 전송 방지, 사진 지원, 로그인 만료 후 동작은 확인하지 않았다. 홍보 문구만으로 이 세 항목을 지원한다고 결론 내리지 않는다.

비교할 때 기기 저장과 서버 반영을 어떻게 구분해 알리는지 먼저 보자는 의견이 나왔다. 이용자 수나 가격은 두 서비스 모두 이번 기록에 없으며, 다음 조사 범위를 정할 때 확인 가능성을 검토하기로 했다.
