# 두 번째 초안 옆

각 기록은 기기에 처음 저장할 때 만든 고유 식별자를 재시도 때도 그대로 쓴다. 서버는 같은 식별자를 다시 받으면 새 관찰을 추가하지 않고 이미 받은 기록의 확인값을 돌려준다. 연결이 돌아온 것만으로 전송 완료로 바꾸지 않고 서버 확인을 기다리는 것으로 설계를 확정했다.

자동 전송은 앱이 열려 있고 로그인된 상태에서 연결을 확인했을 때 시작한다. 앱이 닫힌 동안의 백그라운드 전송은 이번 버전에서 지원하지 않기로 했다. 화면에는 다시 보내기 버튼을 두되, 이미 전송 중인 기록을 눌러도 동시에 두 요청을 시작하지 않도록 한다.

서버 확인을 받은 직후 앱이 강제 종료되면 기기의 상태 변경이 남지 않을 수 있다. 같은 식별자 재전송으로 서버 중복은 막을 수 있다는 설계 의도지만 이 종료 시점은 아직 시험하지 않았다. 저장 공간이 가득 찼을 때의 안내 문구는 미정이라 화면 담당자가 11월 9일까지 제안하기로 했다.
