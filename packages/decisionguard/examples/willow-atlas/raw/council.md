# 4월 운영회의 · W-03

2027-04-10 채택. Willow Atlas 첫 시험판에서 오프라인 관측은 기기에 저장하고 연결 복구 후 제출한다. 관측자는 제출 전 대기 목록을 확인한다.

W-03은 W-01의 정확한 지점 즉시 공개 방식을 철회한다. 이제 조정자 검토와 관측자 공개 동의가 모두 있는 기록만 250m 격자로 공개한다. 정확한 지점은 시민 지도에 보내지 않는다. 이 공개 방식은 채택되었다.

GRID-2의 답변은 250m 격자다. 공개 격자 수치는 확정됐지만 실제 위치 노출 검사는 아직 실행하지 않았다.

지도 공개 전 접근성 검토와 위치 노출 검사를 완료해야 한다는 순서를 채택했다. 내부 화면 데모는 시민 공개 승인이 아니다.

보관 기간은 이번 회의에서 결정하지 않았다. 보존 메모가 아직 도착하지 않아 다음 검토가 필요하다.
