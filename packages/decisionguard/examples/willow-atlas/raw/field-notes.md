# 현장 메모 모음

현장 모임에서 나온 말과 작업 중에 적은 메모를 한곳에 모았다.

| 항목 | 들은 말 또는 확인한 내용 | 근거의 한계 |
| --- | --- | --- |
| 입력 작업 | 가상 인터뷰 6팀 중 3팀이 종이 관측을 저녁에 다시 입력한다고 말했다. | 팀 진술이며 시간 절감 실험은 없다. |
| 관심 | 두 조정자가 무료 체험에 참여할 의향을 밝혔다. | 유료 구매나 갱신 약속은 아니다. |
| 현재 대안 | 여섯 팀은 종이 수첩과 무료 설문 폼을 함께 사용한다고 보고했다. | 가상 인터뷰 관찰이며 전체 시장 점유율은 아니다. |
| 아이디어 | 손목 장치 자동 기록을 언젠가 검토하자는 제안이 나왔다. | 승인되지 않았고 이번 오프라인 제출 범위 밖이다. |
| 업무 흐름 | 제출 전 관측자는 자기 기기의 대기 목록을 확인할 수 있어야 한다. | W-03 운영회의에서 채택한 요구를 옮겼다. |
| 기대 효과 | 중복 입력 감소가 유료 도입으로 이어질 수 있다는 가설이다. | 가격 제안과 실제 구매 실험은 미실시다. |
| 표시 문구 | 지도의 제목을 '우리 동네 기록'으로 바꾸자는 제안이다. | 운영위원회에서 검토하지 않은 홍보 문안이다. |

위 진술과 아이디어는 지도 공개나 관측 데이터 이용의 승인이 아니다.
